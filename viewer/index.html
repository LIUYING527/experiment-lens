Get started

1 · 先看自己的数据

把 JSON、JSONL、NDJSON 或 CSV 日志直接拖进窗口，或点下面选择文件。

2 · 运行一个演示

在项目根目录的终端执行；演示会生成可视化事件，不会训练真实模型。

python examples/training_demo.py
3 · 接入自己的 Python 程序

只需安装 SDK，再在代码中发送事件；详细协议和示例可后续按需查看。

python -m pip install -e ./sdk/python
在 Python 中使用 from experiment_lens import Lens，然后调用 Lens.event(...) 或指标接口。SDK 会向本机 Viziverse 服务发送事件（127.0.0.1:7337）。
快捷操作：拖入日志即可导入；导入只进入当前窗口会话，点“Export JSON”可保存副本。
